# 第8组｜5分钟交流演示

## 直接使用

双击 `00_打开5分钟汇报.html`，使用 Chrome 或 Edge。HTML是单文件，断网也能翻页、查看讲稿和操作课堂演示，不需要安装依赖。

开始分享屏幕后再点“开始5分钟”。前4分钟讲述和展示，最后1分钟留给老师答疑；4分钟会显示答疑提醒，5分钟显示结束提醒。

严格按老师给的顺序：**帮谁 → 用哪张表 → 按什么规则 → 产出什么 → 由谁拍板**。第6页只供答疑，不扩展新的介绍主线。

| 页 | 讲述与操作 | 时长 | 累计 |
| --- | --- | --- | --- |
| 帮谁 | 制作岗位的现有备餐计划是否还能及时满足需求 | 35秒 | 0:35 |
| 用哪张表 | 高峰经营快照，来源、模拟与派生分清 | 40秒 | 1:15 |
| 按什么规则 | 已有待办与需用时点对照，手算第10分钟1份迟供 | 45秒 | 2:00 |
| 产出什么 | 操作“延期→核对→采纳→完成复评” | 65秒 | 3:05 |
| 由谁拍板 | AI、程序、制作岗位、店长分工；人审四要素 | 55秒 | 4:00 |
| 答疑 | 请老师核对普通调整与规则例外的权限边界 | 60秒 | 5:00 |

主讲稿约720字，动作时间包含在各页时间里。练习时按本人语速调整停顿，答疑备答按老师追问选用，不全部朗读。

## 第4页演示顺序

1. 点“注入唯一延期”，指出原8份任务第12分钟才完成，模拟第10分钟1份迟供。
2. 指出候选是原8份改到第8分钟，新增0。
3. 勾选课堂核对，再点“课堂采纳”。在手仍12，说明采纳不等于完成。
4. 点“模拟完成与复评”。登记完成8、已履约4后，在手16、可分配11；剩余模拟需用11，展示已保存的真实AI复评。
5. “缺制作规则”和展开工具证据留给答疑，不必在65秒演示中全部展开。

## 快捷键

- 左右键或PageUp/PageDown：翻页；Home/End：首末页。
- 空格：翻下一页（按钮有焦点时保留按钮本身操作）。
- N：逐页讲稿与操作提示。投影时可只分享主页面，先用讲稿练习。
- F：全屏；浏览器不允许时可用F11。
- 倒计时可暂停、继续、重置，不自动翻页。

## 与实时智能体的区别

本HTML中的数量由程序即时计算；AI结论来自已保存的三次真实模型调查，证据可展开。页面明确标识，不冒充现场新模型调用。新增互动只记“演示操作者”，不写入实时应用，不替代用户旧课堂确认。

已验证的本地实时智能体可从页面链接打开：`http://127.0.0.1:8765/`。它收到事件后真实调用模型；此前一次调查约61～79秒，不建议在5分钟里重复等待两次。实时应用需要本机服务和模型网络连接。

课堂模拟仍限1店1商品1条外部延期。商品与交易底稿为Scrapling采集；库存、需用时点、制作和可售规则及执行为模拟，尚无企业实测收益。
