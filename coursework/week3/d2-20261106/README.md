## 数据与例外

本例全部经营数值明确标为课堂模拟。既有公开三明治记录仅作清洗与接口参考，不能标为麦当劳真实订单，也不能据此拟合高峰规律。

正常计划可覆盖时不重复制作；缺关键规则暂停受影响候选；缺料上报店长；超过单批上限先拆批；AI不可用时保留已确认计划和基础登记并显示状态。
