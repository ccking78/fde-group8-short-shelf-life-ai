# 版本、来源与交接边界

## 本次内容

基于公开项目提交`c569dc88edf20fbecb8c14a8e8e1f4ac14d2cfe5`：

- `app/`：实时智能体v0.3的Windows交接适配副本。
- `presentation/`：原五分钟HTML、讲稿和核验记录，原字节保留。
- `.runtime/python/`：官方Python嵌入式运行时及随应用提供的依赖。
- `tools/`：文件校验、环境自检、本人登录、真实模型试跑和启动辅助。
- `historical-evidence/`：以前发生的真实模型运行、课堂测试及提交证据，明确是历史记录。

为跨电脑运行，调整CLI发现、本机数据默认目录、启动提示和默认测试路径，并为Windows服务增加端口独占绑定，避免与其他程序重叠监听；库存/模拟/人工确认/完成账务及工具协议不变。`source-provenance.json`记录原源码哈希和下载来源。旧ZIP与原目录不改。

本包生成时，D1 v2已提交，回执`R261104151942-46852`；源码已推到主题分支并建PR #2，待组员检查。旧交付文件里的“GitHub暂缓/尚未上传”属于生成时历史状态，以本说明为当前状态。

## 模型认证与调用

使用组员本机Codex配置，不指定或替换其模型。新安装固定官方CLI 0.166.0；已有可用CLI保留。标准登录使用`codex login`，备用设备码`codex login --device-auth`；能否使用由本人账号、权限、网络和额度决定。

模型每次经`codex exec --json --output-schema`返回结构化业务工具选择，宿主程序执行白名单函数并反馈。每轮90秒，最多5轮；每次真实运行都有新记录。数量校验与业务写入仍由程序负责，模型没有业务写入工具。

交接包不包含auth.json、API key或其他人的模型登录配置。登录状态检测不等于实时连接成功，05真实试跑是目标电脑的检查步骤。

## 第三方运行组件

| 组件 | 来源与核对 |
| --- | --- |
| Python 3.13.17 Windows x64 embedded | [Python官方发布](https://www.python.org/downloads/release/python-31317/)，下载SHA256与PSF有效数字签名已核对 |
| SimPy 4.1.2、jsonschema 4.25.1及传递依赖 | PyPI二进制wheel，具体固定版本和哈希见`tools/runtime-lock.json`，随应用提供；许可证保留在各dist-info目录 |
| Codex安装脚本 | [官方脚本](https://chatgpt.com/codex/install.ps1)的固定SHA256副本，包内提供；在组员电脑由官方安装器下载完整CLI |
| 源数据 | Cazier, Spaulding, Hassler (2025), [Sandwich Analytics V1](https://data.mendeley.com/datasets/9hntk3wbwc/1)，CC BY 4.0；来源与许可保存在`app/inputs` |

Python许可在运行时`LICENSE.txt`；第三方依赖许可随`.dist-info`保存。未给小组文档和源码新增统一开源许可。

Python官方将嵌入式发行用于应用私有运行时，并建议依赖随应用提供，见[Windows嵌入式说明](https://docs.python.org/3.13/using/windows.html#the-embeddable-package)。本包不在组员电脑用嵌入式Python运行pip升级。

Codex安装及认证依据：[官方Windows部署](https://learn.chatgpt.com/docs/enterprise/windows-deployment)、[认证](https://learn.chatgpt.com/docs/auth?surface=cli)、[非交互输出](https://learn.chatgpt.com/docs/non-interactive-mode)。官方安装器默认当前用户安装并更新User PATH，CLI仍需网络与本人可用模型账号。

## 真实性与验收

仍限一店一商品一条延期，公开记录只支持商品与交易底稿；库存、需用时点、规则和执行均为课堂模拟，没有企业实测收益。

离线HTML为即時計算加冻结AI证据；实时应用才发起新模型请求。生成交接包不等于已部署到组员电脑。目标电脑须通过02自检与05试跑，结论才可由部署AI记录。
