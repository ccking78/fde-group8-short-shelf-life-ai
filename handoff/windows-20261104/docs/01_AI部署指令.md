# 给组员电脑上的AI：直接执行的部署任务

把下面内容和整个解压目录一起交给**有本机文件与终端权限的AI**。网页聊天AI只能指导，不能替你实际操作电脑。登录网页由组员本人完成。

---

请在这台Windows 10/11电脑部署当前文件夹里的“第8组高峰经营异常助手”，并教我演示。目录是一个完整交接包，先读根目录`00_先读.txt`、`docs/02_汇报人操作卡.md`、`docs/03_troubleshooting.md`和`docs/04_交接版本与来源.md`。

## 目标

1. 我今天负责小组5分钟汇报。先打开`presentation/00_打开5分钟汇报.html`，确认可离线翻页，N显示讲稿，4分钟讲述展示、1分钟答疑。
2. 再配置本机实时智能体，完成一次真实模型与业务工具调查，最后告诉我如何启动、操作、停止与查看报告。

## 执行顺序

1. 确认已经完整解压到可写目录；不要在ZIP内执行。此包自带Windows x64 Python 3.13.17和锁定依赖，先使用随包运行时，避免另装环境。
2. 在PowerShell中运行`02_环境自检.cmd`。自动化时仅在当前进程设`$env:FDE_HANDOFF_NO_PAUSE='1'`，避免CMD暂停。也可以直接：

   ```powershell
   & '.\.runtime\python\python.exe' -X utf8 -B '.\tools\handoff.py' check
   ```

3. 自检不调用模型。核对完整文件清单、依赖、输入及10项关键业务边界。若清单不符，重新完整解压，不直接改清单以掩盖差异。
4. 若没有CLI，运行`03_安装Codex_仅首次.cmd`：包装脚本先核对官方安装脚本SHA256，然后调用它安装固定版本0.166.0，使用当前Windows用户。需联网。已有CLI保持其安装与配置，不降级。不要只复制别台电脑的codex.exe；完整官方CLI可能包含必要的相邻运行文件。
5. 运行`04_登录组员模型.cmd`，由我在官方页面登录自己的账号。若我已配置能用的模型/provider，保持原配置，先试跑。不得要求傅浩诚发送auth.json、API key或账号密码，不把凭据写入交接包或聊天。正常登录遇到回调问题时，可由我选择`07_设备码登录备用.cmd`；设备码功能需本账号允许。
6. 运行`05_真实AI试跑.cmd`。它会用本机配置发起一次真实延期调查，可能消耗额度；最多5轮，每轮90秒。试跑独立存储，不采纳建议、不登记完成、不冒充真实人审。检查输出成功、模型请求数大于0、有真实业务工具记录、建议原8份改到第8分钟且新增0。标准登录检测本身不能证明模型可用；必须以这次试跑为准。
7. 运行`06_启动实时智能体.cmd`，确认`http://127.0.0.1:8765/`能打开。窗口须保持打开，Ctrl+C停止。保持仅127.0.0.1监听。
8. 教我按操作卡完成一次课堂操作。人审由我核对并点击；不要替我编造采纳记录。保存、导出本次记录时标“组员课堂演示”，不能声称企业实测。

## 路径与故障

- 账本默认在`%LOCALAPPDATA%\FDEGroup8\agent-v0.3`；自检与真实试跑在同级`handoff-reports`。可以用当前进程`FDE_AGENT_WORK`/`FDE_HANDOFF_REPORT_DIR`改到用户指定目录。
- 包内不依赖傅浩诚电脑的F/E盘；不要把旧源码或旧运行报告里的路径照搬。
- CLI自动查找原生exe、官方用户安装、Codex桌面运行时及常见npm原生文件。如需指定，当前进程设置`FDE_CODEX_EXE`为这台电脑完整原生exe路径，不指向cmd/ps1。
- 端口冲突时先识别服务，不结束陌生进程。已有v0.3服务会保留并打开；其他服务可用`handoff.py start --port 8770`，把新地址告诉我。离线HTML里的实时按钮固定指向8765，改端口后请手动打开新地址。
- 不改全局PowerShell执行策略，不关闭证书校验或系统防护，不开放公网端口；组织策略阻止脚本时遵循策略。
- 如果当前账户/网络不能真实运行，保留明确失败状态；今天仍用离线HTML和冻结证据汇报，不把回放改名为实时调用。
