# 给李启顺：今天如何讲、如何操作

## 先记住一句话

我们帮**门店制作岗位**，用**高峰经营快照表**，按**已有待办和需用时点逐点对照**，产出**有证据的调整候选与核对项**，由**制作岗位决定普通调整、店长管理规则和例外**。

## 五分钟安排

| 页面 | 讲什么 | 时间 |
| --- | --- | --- |
| 1 帮谁 | 已有备餐计划还能否赶上，不要重复加做 | 35秒 |
| 2 用哪张表 | 库存、待办、需用时点、规则和来源 | 40秒 |
| 3 按什么规则 | 第10分钟缺1份是时点问题，比较提前原待办 | 45秒 |
| 4 产出什么 | 点延期→核对→采纳→完成复评 | 65秒 |
| 5 由谁拍板 | AI、程序、制作岗位、店长；人审四要素 | 55秒 |
| 6 答疑 | 请老师核对普通调整与规则例外的权限边界 | 60秒 |

主讲用`01_打开5分钟汇报.cmd`。开始分享屏幕后点击“开始5分钟”；N查看逐页稿，F全屏，左右键翻页。完整逐字稿在`presentation/01_逐页讲稿与答疑备答.md`。备答按追问选用，不全部读。

## 第4页离线互动（主讲65秒）

1. 点“注入唯一延期”：原8份第12分钟才完成；第10分钟累计需用8，先有可分配7，所以1份模拟迟供。
2. 指出建议：调整**原8份**到第8分钟，**额外新增0**。
3. 勾选课堂核对，点“课堂采纳”：库存仍12，说明采纳不等于完成。
4. 点“模拟完成与复评”：完成8、已履约4，库存12+8−4=16，可分配16−5=11；剩余模拟需用11。
5. 说明本页即时计算数量，并展示此前真实AI调查与复评的记录；它不是新模型请求，也不写入实时应用。

“缺制作规则”和工具证据可留答疑。默认原计划第4分钟完成正常；延期是唯一外部增量，不要把4→12→8说成三次真实企业事件。

## 实时智能体（课前或答疑另外展示）

先确认`05_真实AI试跑.cmd`已成功，运行`06_启动实时智能体.cmd`后保持窗口打开。

1. **新建正常情景**：在手12，预留5，不可分配0，可分配7；原待办8份、第4分钟完成。
2. **登记唯一延期**：原任务预计完成4→12，自动触发新模型调查。先等页面调查结束；之前制作电脑约61～79秒，组员电脑速度可能不同。不要连续重复点。
3. **查看工具记录**：说明模型查询快照、任务与规则，调用比较工具后生成建议。预期原8份改到第8分钟，新增0；以本次真实结果为准，失败就直说连接失败。
4. **由你核对**：操作者写“李启顺（课堂演示）”。核对现场进度/产能/制作规则/数量与时点都是课堂设定，理由可写“按本次课堂假设核对原TASK-8及候选8份、第8分钟完成，新增0”。勾核对后由你采纳。此时在手仍12。
5. **模拟完成**：完成数量8、时点8、累计已履约4，核对后勾课堂登记并提交；在手16、可分配11，新事实触发新模型复评。
6. **导出本次完整记录**：供答疑展示新运行留痕。少完成或履约未知时不能直接宣称正常；缺制作时间时可采纳数量应为空。

完整两轮实时模型可能超过2分钟，不要在5分钟里临时等待两轮。主讲先用离线HTML，老师追问时再打开真实运行与工具记录。

## AI与人的分工

| 角色 | 负责什么 | 必须核对的边界 |
| --- | --- | --- |
| AI | 选择证据与业务工具、形成候选、解释与复评 | 不能批准调整或直接写库存 |
| 程序 | 数值计算、规则与版本校验、幂等及账务 | 采纳不入库，完成才入账一次 |
| 制作岗位 | 核事实，决定普通采纳/改量/忽略，登记完成 | 改量须重新校验并留理由 |
| 店长 | 确认有效规则、处理例外、审阅复盘 | 缺规则不能靠AI编造 |

人审四要素：**谁确认、看什么、能改什么、怎么留痕**。看原任务、候选差异、证据和缺项；可采纳/改量/忽略；留操作者、时间、版本、理由和实际完成记录。

## 老师追问时的短答

- **为什么不是再加做8份？** 原来已有8份，问题是完成太晚。先核实能否提前原任务，避免重复加做。
- **哪里用AI？** 实时应用由模型按事件选择查证和比较工具，再基于结果建议；新事实后重新调查。确定性数量由程序算。
- **数据真实吗？** 商品和交易底稿为Scrapling公开采集；库存、分钟需用、规则和延期是课堂模拟。
- **有企业收益吗？** 尚未做真实门店验证。1份模拟迟供不是实际丢单，不能当收益。
- **AI出错或断网怎么办？** 不生成可采纳的新动作；保留已确认待办和基础登记。现场可用标识明确的离线展示。
- **今天本组想问老师什么？** 普通调整交制作岗位，缺规则与例外交店长，这个权限边界是否合理？
