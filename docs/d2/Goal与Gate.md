## 一 Goal

帮助国际连锁餐饮零售门店的当班店长，在高峰开始前判断一个短保商品的缺货与剩余风险，比较当前计划和候选供给，决定本轮是否调整新增供给。首版限定为一店一品、一个高峰、一次新增供给调整。

演示设定10:00判断、10:15前确认，覆盖11:00—13:00。预期价值是减少可避免的供需错配，并让店长看清依据；暂无同口径真实门店对照，不承诺具体收益或损耗下降比例。Fresh门店0、商品38，90日、2160小时格用于真实记录观察；数量、批次和成本使用独立模拟情景。

## 二 Gate

按教学案例的写法，将目标转成可核对条件。以下定义后续业务成果如何验收；D2完成的是标准与例证，不要求今天实现系统。

G1 来源可追溯：真实记录注明来源、原行号、单位和时间，模拟参数逐项明示。对照源快照与字段字典抽查6条真实记录；两来源不拼成同一门店。

G2 能区分正反例：5个模拟情景均有明确预期，正常例不误报，缺失例不出数量。逐例审阅判断和理由；当前核对案例定义，系统实现后另记实际表现。

G3 建议有依据：列明当前状态、候选结果、约束与假设。4个可计算情景按分时账复算数量与比较损失，金额差不超过0.01元；当前只完成情景算术复核。

G4 店长确认后执行：建议须经店长确认，修改后重算，关键资料缺失先补录。通过审阅确认要求及缺失例核验；当前为流程定义，尚无实际操作记录。

## 三 模拟正反例

教师对“公开真实数据结合明示情景状态，是否满足阶段要求”的意见是“使用正反例来解决”。以下5例专门说明何时提醒、何时不提醒，以及资料不足时怎么办；属于本组拟定的验证例证。

### 固定输入

模拟门店SIM-01、商品SIM-SKU-01：10:00判断、10:15确认；期初可售10份，13:30到期，无在制。10:00—11:00需求为0。新增候选0—3批，每批12份，一条产线每批45分钟，依次11:00、11:45、12:30可售；各批完成后可售120分钟。按先到期先卖，13:00对余量按零残值清场。

模拟售价24元，变动成本9.98元；比较损失＝未满足需求×14.02＋未售余量×9.98。选择损失最小的可行候选，并列时选新增较少者。以上均为情景设定，不是门店SOP；不与公开缩放销量换算或拼接。

| 案例 | 输入变化 | 预期判断与已有复核 |
| --- | --- | --- |
| SIM-P1 / 缺货正例 | 原计划0批；11—12点需求24份、12—13点16份，各小时内均匀到达。 | 应提醒缺货。0批缺货30份；3批缺货0、余量6，损失59.88元，为该情景最小值。 |
| SIM-N1 / 正常反例 | 仅将需求改为6份加4份，原计划仍为0批。 | 维持0批；缺货0、余量0、损失0，不新增风险提醒。 |
| SIM-P2 / 过量正例 | 与N1相同，但原待开工计划为1批。 | 应提醒过量。原计划余量12、损失119.76元；取消该未开工批次后均为0。 |
| SIM-N2 / 时序反例 | 与P1总需求相同，但后16份均匀集中于12:00—12:30。 | 应改为2批：缺货6、余量0、损失84.12元；3批损失203.88元。3批并非总是最优。 |
| SIM-B1 / 缺失边界例 | 与P1相同，但期初库存到期时间未知。 | 标待补录并转人工；不给新增批数，不归入正常。本例只定义预期处置。 |

四个可计算情景已做算术复核；缺失例尚无系统执行记录。D1历史复合批次案例的原库存与在制参数不同，不混用。

## 四 真实记录的正反例与边界

6条记录沿用D1的06_真实记录验收示例.csv，可按source_record_id定位。它们用于核对字段和解释，不提供真实新增供给标签。主序列为Fresh门店0、商品38，90日、2160小时格。

| 来源与编号 | 真实记录 | 应作出的判断 |
| --- | --- | --- |
| CASE01 / Fresh train:1 | 门店0商品38；2024-03-29 21:00；销量0，缺货标记1。 | 正例：提示销量受缺货影响；不把零销售解释为零需求。 |
| CASE02 / Fresh train:0 | 同店同品；2024-03-28 06:00；销量0，缺货标记0。 | 反例：不凭零销售添加缺货标签，也不据此证明潜在需求为0。 |
| CASE03 / Fresh train:3 | 同店同品；2024-03-31 11:00；销量0，缺货标记1。 | 午段观察销量不能直接当作潜在需求真值。 |
| CASE04 / Fresh train:67 | 同店同品；2024-06-03 19:00；销量0.1，缺货标记1。 | 两字段都保留；缺货标记不表示整个小时完全无货。 |
| CASE05 / Green train:0 | store_5；2021-08-02；ordered、unsold为空。 | 保留缺失；不填0，不写成没有余货。 |
| CASE06 / Green train:1675 | store_7；2022-07-05；sales、ordered、unsold约为0.7752、0.7320、−0.9741。 | 保持原缩放值；共同尺度未确认，不计算实物守恒或真实报损率。 |

CASE01与CASE02的日期、时段不同，只说明解释边界，不能作为因果对照。11个案例均非随机抽样；案例复核不等于模型准确率，也不能证明真实经营收益。
